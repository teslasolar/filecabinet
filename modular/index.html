🔬 Modular Structure

Each modular app follows this pattern:
• index.html: Structure only (~50 tokens)
• style.css: All styles (~150 tokens)
• core.js: App initialization (~200 tokens)
• algorithms.js: Core logic (~250 tokens)
• viz.js: 3D visualization (~200 tokens)
• ui.js: UI updates (~150 tokens)

Total: Usually 6-8 files, all under 250 tokens each for easy understanding and modification.
